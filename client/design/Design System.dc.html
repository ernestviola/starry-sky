System rules
Surfaces
Use background for the page, panel for containers, and raised only for nested controls.
States
Accent communicates action and selection; success, warning, and danger are reserved for feedback.
Motion
Use fast for feedback, normal for state changes, and slow for page or panel entrance. Respect reduced motion.
Responsive handoff
Treat these tokens as the shared source for the future mobile system; map them to platform-specific components rather than duplicating values.
